# SECTION A — DAILY STARTUP COMMANDS

### 1. Check your Ubuntu identity
```bash
whoami
```
Purpose: Displays your current Linux username.

### 2. Connect your Alchemy RPC endpoint
```bash
read -rsp "Enter Ethereum RPC URL: " ETH_RPC_URL
echo
export ETH_RPC_URL
```
Purpose: Securely enters the RPC URL and stores it in a temporary environment variable.

Paste your endpoint when prompted. If terminal paste causes problems, use right-click paste.

### 3. Start your local Ethereum fork
```bash
anvil --fork-url "$ETH_RPC_URL" --chain-id 73571
```
Purpose: Starts Anvil using Ethereum Mainnet's state as its starting point, with local Chain ID 73571.

IMPORTANT: Keep this terminal open while working.

### 4. Verify your local blockchain
Open a second Ubuntu terminal:
```bash
cast chain-id --rpc-url http://127.0.0.1:8545
```
Expected result:
```text
73571
```
Purpose: Confirms that the local blockchain is responding.

# SECTION B — BLOCKCHAIN ACCOUNT COMMANDS

### 5. List available Anvil accounts
```bash
cast rpc eth_accounts --rpc-url http://127.0.0.1:8545
```
Purpose: Lists the local development accounts generated by Anvil.

### 6. Check an account's ETH balance
```bash
cast balance ACCOUNT_ADDRESS --ether --rpc-url http://127.0.0.1:8545
```
Purpose: Retrieves an account's ETH balance in ETH units.

Replace ACCOUNT_ADDRESS with the actual wallet address.

### 7. Check the latest block number
```bash
cast block-number --rpc-url http://127.0.0.1:8545
```
Purpose: Shows the latest block number on the local blockchain.

### 8. Check the network ID
```bash
cast chain-id --rpc-url http://127.0.0.1:8545
```
Purpose: Identifies which blockchain network the RPC endpoint is connected to.

# SECTION C — TRANSACTION COMMANDS

### 9. Send ETH between local accounts
```bash
cast send RECEIVER_ADDRESS \
  --value 0.01ether \
  --from SENDER_ADDRESS \
  --unlocked \
  --rpc-url http://127.0.0.1:8545
```
Purpose: Sends 0.01 simulated ETH from one unlocked Anvil account to another.

Only use this with our local development accounts.

### 10. Inspect a transaction
```bash
cast tx TRANSACTION_HASH --rpc-url http://127.0.0.1:8545
```
Purpose: Retrieves transaction details using its hash.

### 11. Check a transaction receipt
```bash
cast receipt TRANSACTION_HASH --rpc-url http://127.0.0.1:8545
```
Purpose: Checks whether a transaction was included in a block and whether it succeeded.

# IMPORTANT SECURITY RULES

1. Never publish your Alchemy API key or RPC URL.
2. Never upload private keys or wallet recovery phrases to GitHub.
3. Never use Anvil-generated private keys with real funds.
4. Keep API credentials out of GitHub repositories.
5. Use local accounts and simulated funds for laboratory exercises.
6. Only test external smart contracts within their explicitly authorised scope.
